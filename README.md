لجعل ملف repomix.config.json مثاليًا ومخصصًا تمامًا لمشروع BeaconAI (المبني
بمعمارية Monorepo و Very Good CLI لسطح المكتب)، قمنا بتطوير وتخصيص الإعدادات
التالية:

1. إضافة headerText: لإعطاء مقدمة للذكاء الاصطناعي يفهم من خلالها أن هذا مشروع
   Flutter Desktop مخصص لمساعدة الكفوفين وتقسيمه إلى packages/ و lib/.
2. إضافة topFiles: لتحديد الملفات المحورية (مثل pubspec.yaml و bootstrap.dart و
   assistant_repository.dart) ليقرأها الذكاء الاصطناعي في بداية الملف أولاً قبل
   بقية الأكواد، مما يجعله يفهم المعمارية فوراً.
3. تحديث الـ customPatterns: استخدام الـ Wildcards المتقدمة (**/) لضمان استبعاد
   ملفات البناء والملفات المولدة تلقائياً داخل كل الحزم (packages/) وليس
   المشروع الرئيسي فقط، بالإضافة لاستبعاد ملفات الـ pubspec.lock لتوفير مساحة
   الـ Tokens.

ملف repomix.config.json المحدث والمخصص للمشروع:

قم باستبدال محتوى ملف repomix.config.json في الجذر الرئيسي للمشروع بهذا الكود:

{
  "$schema": "https://json.repomix.com/schema.json",
  "output": {
    "filePath": "beaconai_context.xml",
    "style": "xml",
    "headerText": "BeaconAI: AI-powered desktop voice assistant for visually impaired users.\nArchitecture: Flutter Monorepo (Very Good CLI pattern) with local packages in packages/ and UI features in lib/.",
    "removeComments": false,
    "showLineNumbers": true,
    "topFiles": [
      "pubspec.yaml",
      "lib/bootstrap.dart",
      "lib/main_development.dart",
      "lib/app/view/app.dart",
      "packages/assistant_repository/lib/src/assistant_repository.dart",
      "packages/assistant_repository/lib/assistant_repository.dart"
    ]
  },
  "ignore": {
    "useGitignore": true,
    "useDefaultPatterns": true,
    "customPatterns": [
      "**/build/",
      "**/.dart_tool/",
      "**/.idea/",
      "**/.vscode/",
      "**/*.g.dart",
      "**/*.freezed.dart",
      "**/*.mocks.dart",
      "**/*.lock",
      "windows/flutter/ephemeral/",
      "windows/runner/Debug/",
      "windows/runner/Release/",
      "*.iml",
      ".metadata",
      "beaconai_context.xml",
      "repomix-output.xml"
    ]
  }
}

## Getting Started 🚀

This project contains 3 flavors:

- development
- staging
- production

To run the desired flavor either use the launch configuration in VSCode/Android Studio or use the following commands:

```sh
# Development

# Staging
$ flutter run --flavor staging --target lib/main_staging.dart

# Production
$ flutter run --flavor production --target lib/main_production.dart
```

_\*Temp App works on iOS, Android, Web, and Windows._

## Working with Translations 🌐

This project follows the [official internationalization guide for Flutter][internationalization_link] using [ARB files][arb_documentation_link] for translations.

### Adding Strings

1. To add a new localizable string, open the `app_en.arb` file at `lib/l10n/arb/app_en.arb` and add a new key/value pair with the relevant description (optional):

```arb
{
    "@@locale": "en",
    "counterAppBarTitle": "Counter",
    "@counterAppBarTitle": {
        "description": "Text shown in the AppBar of the Counter Page"
    },
    "helloWorld": "Hello World",
    "@helloWorld": {
        "description": "Hello World greeting."
    }
}
```

1. Use the new string:

```dart
import 'package:temp_app/l10n/l10n.dart';

@override
Widget build(BuildContext context) {
  final l10n = context.l10n;
  return Text(l10n.helloWorld);
}
```

### Adding Supported Locales

Update the `CFBundleLocalizations` array in the `Info.plist` at `ios/Runner/Info.plist` to include the new locale.

```xml
    ...

    <key>CFBundleLocalizations</key>
	<array>
		<string>en</string>
		<string>es</string>
	</array>

    ...
```

### Adding Translations

1. For each supported locale, add a new ARB file in `lib/l10n/arb`:

```
├── l10n
│   ├── arb
│   │   ├── app_en.arb
│   │   └── app_es.arb
```

1. Add the translated strings to the new `.arb` file:

`app_es.arb`

```arb
{
    "@@locale": "es",
    "counterAppBarTitle": "Contador",
    "@counterAppBarTitle": {
        "description": "Texto mostrado en la AppBar de la página del contador"
    },
    "helloWorld": "Hola Mundo",
    "@helloWorld": {
        "description": "Saludo Hola Mundo."
    }  
}
```

### Generating Translations

To use the latest translations changes, you will need to generate them:

```sh
flutter gen-l10n --arb-dir="lib/l10n/arb"
```

Alternatively, run `flutter run` and code generation will take place automatically.
